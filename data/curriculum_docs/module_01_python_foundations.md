# Module 1: Python Foundations for Agentic AI
Sprints Advanced Agentic AI bootcamp. Duration: 1 week. Prerequisite: none.

## Learning goals
Learners write clean Python functions, use lists, dictionaries, and comprehensions, handle exceptions with try/except, and write simple unit tests with assert statements.

## Assignment 1: Python assignment
Learners submit a function file. The Sprints auto-grader runs the code against hidden assert tests. A score of 70 or above is required to unlock Module 2. Late submissions lose 5 points per day.

## Key concepts
- Functions and return values
- Exceptions: always catch specific exception types, never a bare except
- Docstrings: every function needs a docstring describing inputs and outputs
